1. Python

Bahasa pemrograman serbaguna dengan sintaks yang mudah dibaca. Cocok untuk belajar logika, otomasi, analisis data, dan AI.

Menampilkan teks

print("Halo dunia!")

Variabel & hitung

nama = "Rizki"
umur = 16
hasil = 10 + 5
print(nama)
print(hasil)

Pola penting

# Kondisi
if nilai >= 75:
    print("Lulus")
else:
    print("Belajar lagi")

# Perulangan
for angka in range(1, 4):
    print(angka)

# Fungsi
def tambah(a, b):
    return a + b

Catatan: Python memakai indentasi untuk menandai blok kode.

🟨

2. JavaScript

Bahasa pemrograman yang banyak dipakai untuk membuat website hidup, misalnya tombol, validasi formulir, dan aplikasi web.

Menampilkan teks

console.log("Halo dunia!");

Variabel & hitung

const nama = "Rizki";
let umur = 16;
const hasil = 10 + 5;
console.log(nama);
console.log(hasil);

Pola penting

// Kondisi
if (nilai >= 75) {
  console.log("Lulus");
} else {
  console.log("Belajar lagi");
}

// Perulangan
for (let i = 1; i <= 3; i++) {
  console.log(i);
}

// Fungsi
function tambah(a, b) {
  return a + b;
}

Catatan: kurung kurawal { } membatasi blok; titik koma sering dipakai di akhir pernyataan.

⚙️

3. C++

Bahasa pemrograman yang dikompilasi, sering digunakan saat kontrol dan performa program penting.

Menampilkan teks

#include <iostream>
using namespace std;
int main() {
    cout << "Halo dunia!" << endl;
    return 0;
}

Variabel & hitung

#include <iostream>
using namespace std;
int main() {
    int a = 10, b = 5;
    int hasil = a + b;
    cout << hasil << endl;
    return 0;
}

Pola penting

if (nilai >= 75) {
    cout << "Lulus";
} else {
    cout << "Belajar lagi";
}

for (int i = 1; i <= 3; i++) {
    cout << i << endl;
}

Catatan: program C++ biasanya perlu dikompilasi sebelum dijalankan.

Operator dasar (“rumus”)

Aritmetika

+  tambah       8 + 2 = 10
-  kurang       8 - 2 = 6
*  kali         8 * 2 = 16
/  bagi         8 / 2 = 4
%  sisa bagi    8 % 3 = 2

Perbandingan & logika

== sama dengan
!= tidak sama
>  lebih besar
<  lebih kecil
>= lebih besar/sama
<= lebih kecil/sama
&& / and  DAN
|| / or   ATAU
! / not   BUKAN

Operator tersedia dengan detail berbeda di tiap bahasa. Misalnya Python memakai and/or, sedangkan JavaScript dan C++ memakai &&/||.

Uji coba kode langsung

Pilih bahasa, edit kode, lalu tekan Run. JavaScript berjalan langsung di browser; Python memakai Pyodide dan C++ memakai layanan kompilasi online.

Jangan masukkan kata sandi, token, atau data pribadi ke kode. Python dan C++ membutuhkan koneksi internet untuk memuat mesin eksekusinya.
