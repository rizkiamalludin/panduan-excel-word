Microsoft Excel

Rumus & Fungsi Wajib Excel

Semua rumus diawali tanda =. Contoh memakai pemisah koma ,; pada beberapa versi Excel Indonesia gunakan titik koma ;.

SUM

Aritmatika

Menjumlahkan semua angka dalam rentang sel. Rumus paling sering dipakai di Excel.

=SUM(A1:A10)

Contoh: =SUM(B2:B6) jika B2–B6 berisi 10, 20, 30, 40, 50 → hasil 150.

AVERAGE

Aritmatika

Menghitung rata-rata aritmetika dari rentang angka (jumlah dibagi banyak data).

=AVERAGE(B2:B6)

Contoh: data 10, 20, 30, 40, 50 → hasil 30.

MAX & MIN

Arithmatika

MAX mengambil nilai tertinggi, MIN mengambil nilai terendah dari rentang data.

=MAX(A1:A10)
=MIN(A1:A10)

Contoh: data 8, 15, 3, 22 → MAX = 22, MIN = 3.

COUNT / COUNTA

Statistik

COUNT menghitung sel berisi angka; COUNTA menghitung sel yang tidak kosong (teks maupun angka).

=COUNT(A1:A10)
=COUNTA(A1:A10)

Contoh: rentang berisi 3 angka dan 2 teks → COUNT = 3, COUNTA = 5.

IF

Logika

Memeriksa kondisi: jika benar menghasilkan nilai A, jika salah menghasilkan nilai B.

=IF(A1>=75,"Lulus","Remedial")

Contoh: nilai 80 → Lulus; nilai 60 → Remedial. Bisa bersarang: =IF(A1>90,"A",IF(A1>75,"B","C"))

VLOOKUP / XLOOKUP

Pencarian

Mencari nilai di kolom pertama tabel lalu mengembalikan nilai dari kolom lain. XLOOKUP (Excel 365) lebih fleksibel.

=VLOOKUP(A2, tabel, 3, FALSE)
=XLOOKUP(A2, kolom_cari, kolom_hasil)

Contoh: cari kode "B02" di tabel harga → otomatis mengambil nama/harga barang tanpa menyalin manual.

COUNTIF / SUMIF

Bersyarat

Menghitung/menjumlahkan data yang memenuhi satu kriteria tertentu.

=COUNTIF(D2:D100,"Laki-laki")
=SUMIF(C2:C100,"Makanan",B2:B100)

Contoh SUMIF: menjumlahkan hanya kolom belanja untuk kategori "Makanan".

CONCATENATE / &

Teks

Menggabungkan beberapa teks/sel menjadi satu. Fungsi modern: TEXTJOIN dengan pemisah.

=A1&" "&B1
=TEXTJOIN(", ",TRUE,A1:A5)

Contoh: "Budi" & " " & "Santoso" → "Budi Santoso".

LEFT / RIGHT / MID

Teks

Memotong teks dari kiri, kanan, atau tengah. LEN menghitung jumlah karakter.

=LEFT(A1,4)
=MID(A1,3,5)
=RIGHT(A1,2)

Contoh: "JAKARTA01" → LEFT 4 = "JAKA", RIGHT 2 = "01".

ROUND

Arithmatika

Membulatkan angka sesuai jumlah desimal yang diinginkan.

=ROUND(3.14159, 2)

Contoh: hasil → 3,14. =ROUND(3.14159,0) → 3.

IFERROR

Logika

Menangani galat (mis. #DIV/0!, #N/A) agar tampil pesan pengganti yang rapi.

=IFERROR(A1/B1,"-")

Contoh: jika B1 = 0 maka tampil "-" alih-alih #DIV/0!.

TODAY / NOW

Tanggal

TODAY menghasilkan tanggal hari ini; NOW tanggal + jam. Nilainya berubah otomatis tiap dibuka.

=TODAY()
=NOW()

Contoh: menghitung sisa hari: =TODAY()-tanggal_selesai.

Tidak ada rumus yang cocok dengan pencarianmu.

Microsoft Excel

Kegunaan Fitur-Fitur Excel

Bukan rumus — ini fitur bawaan Excel dan fungsinya.

AutoSum (Alt + =)

Fitur

Menyisipkan rumus SUM (atau AVERAGE, COUNT) otomatis untuk rentang di atas/kiri kursor — tanpa mengetik.

Format Sel (Ctrl + 1)

Fitur

Membuka jendela Format Sel: atur angka (rupiah, persen, desimal), rata, garis, dan proteksi sel.

Filter Data (Ctrl + Shift + L)

Fitur

Menampilkan tombol panah di tiap kolom header untuk menyaring data — misal hanya menampilkan kategori "Elektronik".

Sort / Pengurutan

Fitur

Mengurutkan data A→Z atau Z→A, menurut angka kecil→besar, bisa dengan banyak kriteria sekaligus.

Conditional Formatting

Fitur

Memberi warna/garis/data bar otomatis berdasarkan kondisi — misal nilai < 75 jadi merah.

PivotTable

Fitur

Merekap ribuan baris data menjadi laporan ringkas (jumlah, rata-rata, hitung) hanya dengan drag & drop.

Chart / Grafik

Fitur

Mengubah angka menjadi grafik batang, lingkaran, garis, dll. Cepat dengan Alt + F1 (grafik di sheet) atau F11 (sheet baru).

Tabel (Ctrl + T)

Fitur

Mengubah rentang menjadi tabel resmi: header otomatis, filter, dan rumus ikut terisi sepanjang tabel.

Data Validation (Dropdown)

Fitur

Membatasi isi sel — misal hanya boleh memilih dari daftar "Ya/Tidak" sehingga data tidak salah input.

Tidak ada fitur yang cocok dengan pencarianmu.

Microsoft Excel

Shortcut Excel & Kegunaannya

Untuk Windows. Cari lewat kotak pencarian di atas, misal ketik Ctrl+A.

Ctrl + A

Pilihan

Memilih seluruh data di sekitar kursor (current region). Jika ditekan sekali lagi (atau saat kursor di area kosong) → memilih seluruh sel di sheet tersebut.

Catatan: di Word, Ctrl+A langsung memilih seluruh dokumen.

Ctrl + C / X / V

Edit

C = salin (copy), X = potong (cut), V = tempel (paste). Kombinasi paling dasar untuk memindahkan data.

Ctrl + Z / Y

Edit

Ctrl+Z = membatalkan aksi terakhir (undo), Ctrl+Y = mengulangi yang tadi dibatalkan (redo).

Ctrl + S

File

Menyimpan file. Biasakan tekan ini berkala supaya pekerjaan tidak hilang.

Ctrl + B / I / U

Format

B = tebal (bold), I = miring (italic), U = garis bawah (underline) untuk teks di dalam sel.

Ctrl + 1

Format

Membuka jendela Format Sel — cara tercepat mengubah tipe angka, alignment, border, dan fill.

Ctrl + Shift + L

Data

Menyalakan/mematikan Filter pada header tabel — untuk menyaring data tanpa menghapusnya.

Alt + =

Rumus

AutoSum — sisipkan rumus SUM otomatis untuk data di atas/kiri, lalu tekan Enter.

F2

Edit

Mengedit isi sel langsung di selnya (setara klik dua kali) — berguna saat memeriksa rumus panjang.

F4

Rumus

Saat mengetik rumus, mengunci referensi sel (A1 → $A$1) supaya tidak bergeser saat rumus disalin. Juga = ulangi aksi terakhir.

Ctrl + Home / End

Navigasi

Ctrl+Home = loncat ke sel A1, Ctrl+End = loncat ke sel terakhir yang berisi data.

Ctrl + Page Up / Down

Navigasi

Berpindah antar sheet (lembar kerja) tanpa harus mengklik tab di bawah.

Ctrl + F / H

Edit

Ctrl+F = mencari teks, Ctrl+H = mencari sekaligus menggantinya (find & replace).

Ctrl + Shift + G

Info

Di Excel: menampilkan jumlah kata/karakter pada pilihan. (Di Word: Word Count.)

Ctrl + ;

Input

Menyisipkan tanggal hari ini sebagai nilai tetap. Ctrl+Shift+; menyisipkan jam.

Ctrl + Space / Shift + Space

Pilihan

Ctrl+Space = memilih seluruh kolom, Shift+Space = memilih seluruh baris.

Tidak ada shortcut yang cocok dengan pencarianmu.

Microsoft Word

Shortcut Word & Kegunaannya

Untuk Windows — mempercepat mengetik dan mengformat dokumen.

Ctrl + A

Pilihan

Memilih seluruh isi dokumen — dari paragraf pertama sampai terakhir — siap untuk dihapus, diformat, atau disalin.

Ctrl + B / I / U

Format

B = tebal, I = miring, U = garis bawah pada teks yang dipilih.

Ctrl + C / X / V

Edit

Salin (C), potong (X), tempel (V) teks, gambar, atau objek apa pun di dokumen.

Ctrl + Z / Y

Edit

Ctrl+Z = batalkan aksi terakhir; Ctrl+Y = ulangi (redo). Bisa ditekan berulang untuk mundur beberapa langkah.

Ctrl + S

File

Menyimpan dokumen. F12 = Save As (simpan sebagai nama/format baru).

Ctrl + L / E / R / J

Format

Perataan paragraf: L = rata kiri, E = rata tengah (center), R = rata kanan, J = rata penuh (justify).

Catatan: rata tengah pakai E (bukan C), karena C sudah dipakai untuk Copy.

Ctrl + 1 / 2 / 5

Format

Spasi baris paragraf: 1 = single, 2 = double (2 spasi), 5 = 1,5 spasi.

Ctrl + F / H

Edit

Ctrl+F = cari teks di dokumen, Ctrl+H = cari & ganti (misal ganti semua "yg" → "yang").

F7

Review

Menjalankan pengecekan ejaan & tata bahasa (spell & grammar check) pada dokumen.

Ctrl + K

Sisipkan

Menyisipkan hyperlink (tautan ke web, file, atau posisi dokumen).

Ctrl + Enter

Format

Memaksa pindah halaman dari posisi kursor — berguna memulai bab baru tanpa menekan Enter berkali-kali.

Shift + Enter

Format

Pindah baris dalam paragraf yang sama (soft return) tanpa membuat paragraf baru.

Ctrl + Space

Format

Menghapus semua format pada teks yang dipilih (warna, ukuran, font) kembali ke gaya normal — isinya tetap ada.

Ctrl + Shift + C / V

Format

Salin format dari teks lain (C) lalu tempelkan ke teks tujuan (V) — format painter versi keyboard.

Ctrl + Shift + G

Info

Menampilkan jumlah kata dokumen (Word Count) — penting saat ada target penulisan.

Ctrl + W

File

Menutup dokumen aktif (jika belum disimpan, muncul pertanyaan penyimpanan dulu).

Tidak ada shortcut yang cocok dengan pencarianmu.

Microsoft Word

Kegunaan Fitur-Fitur Word

Fitur bawaan Word dan fungsinya untuk menyusun dokumen rapi.

Styles (Judul 1, 2, 3…)

Fitur

Menerapkan gaya resmi ke judul/paragraf. Wajib dipakai agar Daftar Isi dan navigasi dokumen bisa dibuat otomatis.

Daftar Isi Otomatis

Fitur

References → Table of Contents: seluruh judul bab + nomor halaman terisi otomatis dan bisa diperbarui dengan satu klik.

Mail Merge (Gabung Surat)

Fitur

Menggabungkan satu template dengan daftar data (Excel) untuk membuat ratusan surat/label — misal undangan dengan nama berbeda-beda.

Lacak Perubahan & Komentar

Fitur

Review → Track Changes: setiap suntingan ditandai, bisa diterima/ditolak satu per satu — standar untuk dokumen kolaborasi & skripsi.

Header, Footer & Nomor Halaman

Fitur

Area tetap di atas/bawah tiap halaman untuk kop, judul dokumen, atau nomor halaman otomatis.

Tabel

Fitur

Menyusun data rapi dalam baris & kolom; bisa diatur lebarnya, digabung selnya, dan diwarnai.

Kolom Teks

Fitur

Layout → Columns: memecah halaman menjadi 2/3 kolom seperti koran/majalah.

Section Break

Fitur

Memisahkan bagian dokumen agar kompas/bab I bisa portrait, lampiran landscape, dengan nomor halaman yang berbeda-beda.

Sisipkan & Format Gambar

Fitur

Insert → Pictures: sisipkan gambar, lalu rapikan dengan crop, text wrapping (bungkus teks), dan border.

Cari & Ganti Massal

Fitur

Mengganti seluruh kemunculan kata dalam sekali jalan — misal mengubah ejaan lama ke ejaan baru di 50 halaman.

Protect Document

Fitur

Membatasi editing (hanya komentar saja, atau dibuka dengan password) supaya dokumen tidak diubah sembarangan.

Simpan sebagai PDF

Fitur

File → Save As → PDF: dokumen jadi PDF yang tampil sama di semua perangkat dan sulit diubah isinya.

Tidak ada fitur yang cocok dengan pencarianmu.
